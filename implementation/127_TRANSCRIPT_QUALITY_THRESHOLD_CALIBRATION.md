The finding is stronger than "the sample is small". Every threshold this corpus supports was tested
against the full lecture the calibration slice was cut from, and **not one of them worked**:

| calibration-derived cut | full-lecture result |
|---|---|
| `no_speech_prob ≥ 0.813` | fires once, on `감사합니다.` — **real speech**. Precision 0 % |

| `compression_ratio ≥ 2.368` | fires **0** times |
| `temperature > 0` | fires **0** times in 2.04 hours |

And the hallucination the full run *did* produce carries entirely unremarkable evidence. Perfect

### Why one lecture cannot be stretched

The failure mode is generated by long silence. Across the whole baseline there are exactly **two**
silent gaps of ≥ 10 s — 90 s and 54 s, 144 s total, **2.0 %** of the lecture — and both lie inside the
single instructor-absence event. The second full run produced three such gaps totalling 210 s, again
all in the same event.

Every hallucination in this corpus comes from that one event. Re-running cannot manufacture a second
instructor absence, so positives scale with **more lectures**, not more compute.

## 2. Labeling protocol — and the gap in it

The protocol requires a person to listen and assign HALLUCINATION / REAL_SPEECH / AMBIGUOUS, and
forbids labels generated by automatic rule.

**No human audio verification was performed in this session, and none exists from earlier ones.** This
bounds every number below and must be read with them.

What was used instead is the phenomenon map in `e2e-results/fixtures/PROVENANCE.md`, resting on three
converging *instrumental and textual* grounds rather than on listening:

1. the baseline emitted **zero** segments across 2746.8–2836.8 and 2842.8–2896.8;
2. `vad_filter=True` removed **all** segments from the silent region (`122`) — an independent detector
   agreeing there is no speech there;
3. the text is semantically impossible for the lecture (`이곳은 한국에서 가장 유명한 곳입니다`, `고추냉이`).

That is strong evidence and it is still **proxy labelling**. Every confusion matrix here is
provisional.

Per the protocol, recognition errors were **not** counted as hallucinations: slice B's `4분자`
(→ `사군자`) and `매난국주기` (→ `매란국죽`) are REAL_SPEECH, as is `선생님은 순댓국도 안 먹으러 갔네`
— a garbled rendering of a real student utterance.

## 6. The hallucination the full run produced

The full run largely got the absence right: 178 s of continuous silence with nothing emitted. It
produced one clear fabrication, `고추냉이` ("wasabi") at 2899.6–2901.6 s, inside a region the baseline
labelled hallucination.

Its decode window, `w106` (2899.6–2926.6 s), is instructive twice over.

```text
w106   nsp 0.259   logp -0.716   cr 0.97   T 0.0
  [650] 2899.6-2901.6  고추냉이                          ← fabrication
  [651] 2917.6-2919.6  선생님은 순댓국도 안 먹으러 갔네   ← real (student utterance, garbled)
  [652] 2922.6-2923.6  아 배고파                          ← real
  [653] 2925.6-2926.6  나 배고프다 갑자기                 ← real
```

**First: the evidence is unremarkable.** Within the full lecture the window sits at the

| signal | value | percentile |
|---|---|---|
| `no_speech_prob` | 0.259 | 67.8 % |
| `compression_ratio` | 0.971 | **1.1 %** |
| `avg_logprob` | −0.716 | 0.7 % |

`no_speech_prob` is ordinary. `compression_ratio` is near the **bottom** — the opposite direction from
the calibration hypothesis, where the positive was the highest value seen. Only `avg_logprob` is
extreme.

That opposition is a real analytical result: the two observed hallucination morphologies have
**opposite** compression signatures. A repetition loop (`고기와 함께 먹는 김치찌개` ×4) compresses well
and drives `compression_ratio` up; an isolated one-word fabrication compresses poorly and drives it
down. A single-direction rule cannot serve both.

**Second: window dilution is now demonstrated, not merely argued.** `w106` is
`contains_hallucination` — one fabrication among three real utterances — and its window value is the
statistic for the whole decode window. Any rule reading a window value as a segment's own property
would either flag all four segments or none. This is exactly what QD-7 prohibits, observed on real
data.

## 7. Repetition analysis

Exact adjacent repetition, no labels needed, measured on both full-lecture runs.

| | baseline run | second full run |
|---|---|---|
| segments | 2,564 | 1,731 |
| repetition runs (≥2) | **22** | **8** |
| R1 (≥2) | 124 seg, 4.84 %, 10.77 /h | 27 seg, 1.56 %, 3.92 /h |
| R2 (≥3) | 96 seg, 3.74 %, 3.92 /h | 15 seg, 0.87 %, 0.98 /h |
| R3 (≥4) | 90 seg, 3.51 %, 2.94 /h | 15 seg, 0.87 %, 0.98 /h |

The burden differs by nearly 3× between two runs of the same media. Worse, the **content** flipped:

```text
baseline R3 flags:  응.x4 · 고기와 함께 먹는 김치찌개 x4 (halluc) · 264랑 264. x4
                    30년대 말에 태평양전쟁… x4 · 왜? x48 · 그래 x26
second run R3 flags: 6월 x4 · 응. x11          ← both real speech; zero hallucinations caught
```

The baseline's two loop-shaped runs (48 and 26) did not recur at all. In the second run **R3's
precision is 0 %** — it flagged month-table reading and an acknowledgement, and caught nothing.

R1 additionally flags month names and `감사합니다` in both runs. **Repetition alone does not separate at
R1, R2, or R3.** The baseline's bimodality — everything ≤ 4 except two runs of 26 and 48 — suggested a
cut near 5; the second run has no run above 11 and its longest is real speech. That cut would have
been fitted to two events that did not reproduce.

## 8. Cross-run and cross-scale validation

Lecture-level holdout is impossible with one lecture. Two weaker holdouts were available and both were
used.

### Held-out A — second run of the same slice

Cuts taken at the tightest separating value on the calibration set, applied unchanged:

| rule | calibration TP/FP/FN | held-out A FP |
|---|---|---|
| `no_speech_prob ≥ 0.468` | 1 / 0 / 0 | **1 window, 11 segments** |
| `temperature > 0` | 1 / 0 / 0 | **1 window, 11 segments** |
| `avg_logprob ≤ −0.572` | 1 / 0 / 0 | 0 |
| `compression_ratio ≥ 1.480` | 1 / 0 / 0 | 0 |
| `high_nsp AND fallback` | 1 / 0 / 0 | **1 window, 11 segments** |
| every other pairwise conjunction, and all-four | 1 / 0 / 0 | 0 |

The falsely flagged window (2918.8–2947.8, `no_speech_prob` 0.529, `temperature` 0.2) covers the
**student utterance and the resumed lecture** — the transition back into speech. Run 2 produced no
hallucination at all, so the conjunctions that "survived" had nothing to find; that is not validation.
Their margins were also thin: run 2's highest `compression_ratio` was 1.46 against a 1.480 cut, and
its lowest `avg_logprob` −0.534 against −0.572.

### Held-out B — the full lecture

The decisive test, and the one summarised in the readiness decision. Of four calibration-derived cuts,
three fired zero times and the fourth fired once — on `감사합니다.`, the instructor thanking the class
at 7353.9 s, which carries the highest `no_speech_prob` in the entire lecture (0.836).

**The single highest-`no_speech_prob` window in 2.04 hours is real speech.**

Meanwhile the actual fabrication (`고추냉이`) was missed by all four. Chasing it after the fact:

| cut set at w106's own value | windows | segments | % of transcript |
|---|---|---|---|
| `no_speech_prob ≥ 0.259` | 88 | 532 | 30.7 % |
| `compression_ratio ≥ 0.971` | 270 | 1,728 | 99.8 % |
| `avg_logprob ≤ −0.716` | 3 | 11 | **0.6 %** |

Only `avg_logprob` reaches it at a tolerable burden — and that is one point again.

## 9. Non-determinism

`122` established the baseline is not reproducible. With evidence preserved, the *shape* of the
non-reproducibility is visible for the first time:

| window | slice run 1 | slice run 2 | identical? |
|---|---|---|---|
| 0 — normal speech 2680.0–2708.8 | nsp 0.033, logp −0.281, cr 1.46, T 0.0 | identical | **yes** |
| 1 — normal speech 2708.8–2723.8 | nsp 0.293, logp −0.447, cr 1.01, T 0.0 | identical | **yes** |
| 2 — **hallucination** 2858.8–2882.8 | nsp 0.813, logp −0.967, cr 2.37, T 0.4 | **absent** | no |
| later | 3 windows, 19 segments | different spans and values | no |

**The reproducible part is the real speech; the non-reproducible part is where the positives live.**
Speech-covered time differed by 30 % (135.8 s vs 104.2 s of a 305 s slice).

Across four passes over the same absence region:

| pass | hallucinated segments there |
|---|---|
| baseline full run | 15 (foreign fragments, `전주시장`, repetition ×4) |
| slice A run 1 | 4 (`이곳은 한국의…` ×3 + 1) |
| slice A run 2 | 0 |
| second full run | 1–2 (`고추냉이`, and `이게 별로 안 예쁘네` at the boundary) |

The positive population is a draw from a stochastic process. A positive count from one pass is not the
number of positives in the media, and a threshold fitted to one pass is fitted to one draw.

## 13. What the next calibration needs

Ordered by how much each would change the conclusion:

1. **≥ 4 more lectures containing an instructor-absence or long-silence event**, ideally from ≥ 2
   instructors. Positives are generated by that condition and by nothing else observed.
2. **Human audio labelling** of every candidate region — no label in this record is audio-verified.
   §14 provides the candidate generator.
3. **≥ 2 runs per lecture**, scoring rules against the union. A rule firing on only one draw is
   unstable by definition.
4. **Lecture-level holdout**, possible at ≥ 3 lectures.
5. **Deliberate negative material** for the false positives already seen: speech resuming after
   silence, closing pleasantries, short replies, month/number list reading, and student speech.
6. **Both hallucination morphologies** represented — repetition loops and isolated fabrications — since
   `compression_ratio` behaves oppositely on them.

A sufficiency target, stated so it can be argued with rather than assumed: **≥ 20 independent positive
windows across ≥ 3 lectures covering both morphologies**, with every candidate rule holding on a
lecture it was not fitted to. This corpus has 1 positive window across 1 lecture.

## 14. Candidate generator for the labelling pass

Label-free and cheap, so the human pass can be targeted rather than exhaustive. A region qualifies when
two independent runs **disagree about whether speech exists there**. On this corpus the rule surfaces
exactly the absence region and nothing else — high recall, small enough to listen to.

This is a labelling aid, **not** a firing rule, and must not become one: it needs two runs and tells
you only that the decoder disagreed with itself.
